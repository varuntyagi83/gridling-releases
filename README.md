# Gridling

Downloads for Gridling, the canvas where Claude Code and Codex work side by side.

This repository holds only the app files. Product page and account: https://gridling.varuntyagi.net

## Download

**[Download the latest Gridling for macOS (Apple silicon)](https://github.com/varuntyagi83/gridling-releases/releases/latest/download/Gridling-arm64.dmg)**

Every version, with its notes: [Releases](https://github.com/varuntyagi83/gridling-releases/releases)

## Install

1. Open the .dmg and drag Gridling into Applications.
2. The app is not notarized yet. The first time, right click Gridling in Applications and choose Open, then Open again.

Gridling needs macOS on Apple silicon. Claude Code and Codex run on your own claude.ai and ChatGPT sign ins.

Prefer the browser? Pro, Team and unlimited accounts can use Gridling at https://gridling.varuntyagi.net/app/
